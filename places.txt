# One place per line:   name = where
#   where = lat,lng          exact spot (Google Maps: long-press the place, copy the numbers)
#   where = any other text   searched in Waze, top result is used

# so write the name the way you think of the place. Edits apply on the next command, no restart.

#
# Example:
# 鬆記雞飯 = 3.1730,101.6640
